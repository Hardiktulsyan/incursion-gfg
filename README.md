# INCURSION: Multiverse Under Siege

Marvel-themed landing page and registration site for a GeeksforGeeks Bennett University chapter event.

**Live:** https://hardiktulsyan.github.io/incursion-gfg/

## Concept
The multiverse is collapsing. A rogue TVA hacker, in the Doctor Doom mold, has breached the timeline, and visitors "engage" to join the resistance. Registering for the event is the way in.

## Features
- Cinematic intro sequence and hero section
- Interactive 3D bust built with Three.js
- Custom cursor and animated UI elements
- Background music (starts on the ENGAGE click, because browsers block autoplay)
- Registration modal that saves entries to Google Sheets and sends a confirmation email (Google Apps Script)
- Responsive layout

## Tech
- HTML, CSS and JavaScript in a single `index.html`
- React and Three.js loaded via CDN
- Google Apps Script backend for registrations
- Hosted on GitHub Pages

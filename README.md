## Deploy
1. Push this whole folder to a new GitHub repo (keep the mp3 at the same level as index.html).
2. Repo Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
3. Your live URL appears at Settings > Pages after ~1 min: https://<username>.github.io/<repo>/
4. Open the live link, click ENGAGE, confirm the real track plays.
5. Submit one test registration, confirm it lands in your sheet/doc + sends the email.
6. Submit: live link + repo link + concept explanation + resources/assets list.
